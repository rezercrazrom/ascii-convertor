## 🎨 How it works
Just put your image file link in line "result = image_to_ascii("")" between quotes:

Take your picture, for my example: "images (1).jpeg"(So it would be "result = image_to_ascii("images (1).jpeg")" in that case)

<img width="225" height="225" alt="images (1)" src="https://github.com/user-attachments/assets/7c772afa-642b-450c-9d65-929134af1ab0" />

Then, run convertor - you receive a .txt file as result of convertation
